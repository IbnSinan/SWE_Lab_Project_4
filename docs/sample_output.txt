===== Mini Text Editor (Command Pattern) =====

--- Automatic demo ---
   Executed : Write "Hello"
   Text     : "Hello"
   Executed : Write " RUET"
   Text     : "Hello RUET"
   Executed : Delete 4 char(s)
   Text     : "Hello "

[Undo]
   Undone   : Delete 4 char(s)
   Text     : "Hello RUET"
[Undo]
   Undone   : Write " RUET"
   Text     : "Hello"
[Redo]
   Redone   : Write " RUET"
   Text     : "Hello RUET"

[New command clears redo history]
   Executed : Write "!"
   Text     : "Hello RUET!"
[Redo]
   Nothing to redo.

[Invalid command]
   [ERROR] Delete count must be at least 1.
